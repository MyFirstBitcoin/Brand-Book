# My First Bitcoin – Brand Assets

Each main folder contains clearly organized materials for easy access and usage.

## 📁 Folder Structure

### 1. Logo & Logo Animations

- **Logo**  
  Primary logo files in various formats.

- **Icons**  
  Standalone icon versions of the logo.

- **Logo + Tagline (3 Variations)**  
  Different configurations of the logo with tagline.

- **Co-branding**  
  Assets prepared for partner collaborations.

- **Final Logo Animation**  
  Includes:
  - Intro
  - Outro
  - Watermark versions

### 2. Profile Pictures

This folder contains five profile picture variations for different digital platforms.

These versions ensure flexibility while maintaining brand consistency.

### 3. Banners

- **LinkedIn Banner**  
  Sized and optimized for LinkedIn profiles.

- **X (Twitter) Banner**  
  Designed for X (formerly Twitter).

- **YouTube Banner**  
  Optimized for YouTube channel display.

### 4. Brand Book

This folder contains the official Brand Book PDF.

Please refer to this document when applying the visual identity across platforms.
